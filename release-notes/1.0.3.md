## Annotate says which permission it needs

When a missing permission stops a recording, Record and the Annotate shortcut now open Annotate's Settings tab with the permissions at the top, and a message names the one to turn on. Before, they opened the Captures tab and nothing seemed to happen. The Screen Recording button asks macOS for access, which adds Bespoke to the Screen Recording list in System Settings, so you only switch it on.

## Triage an Issue

Settings > System has a Triage an Issue button. It starts Claude, Claude Code or Codex on this Mac with Bespoke's logs, permissions and version, so the agent finds the cause and drafts a GitHub issue. It asks before it changes anything or posts.
