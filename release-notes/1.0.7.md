## Say "scratch that" to drop a sentence

Say "scratch that" as its own phrase while you dictate, and Bespoke removes the sentence before it and keeps the rest. "Scratch that itch" stays in the transcript, because the phrase needs a pause on each side. Voice Scratch is on by default. Settings lets you turn it off or change the phrase.

## Less memory

Bespoke now unloads the speech model when a dictation or capture finishes, which frees about 700 MB. The load takes about 300 ms and runs while you record, so you don't wait for it. The Unload model setting is gone, since there is nothing left to choose. The Captures page drops from 1.8 GB to 311 MB by showing thumbnails.

## Annotate

- Dictionary replacements now apply to captures. Before, an entry like "Carrot" to "Karat" worked only in dictation.
- Narration lands on the right keyframe with a Bluetooth microphone, because audio, video and events now share one clock.
- One-stroke arrows and flat circles count as marks.
- When a capture can't be saved, the capsule says so. It used to show Copied and leave the old capture on the clipboard.
- A failed screenshot is skipped. It used to add a made-up frame that an agent could read as your screen.

## Fixes

- Polishing gives up after 60 seconds and pastes the original transcript, so a stalled provider can't hold a dictation.
- Cancelling a dictation restores your Mac's sound when mute while recording is on.
- Two quick settings changes no longer overwrite each other.
- Triage hands the agent a copy of your settings with the API keys removed.
- Tooltips and menus no longer float over Settings and Triage.
- Bespoke no longer trusts the compromised eMudhra certificate authorities.
